\ssr{ЗАКЛЮЧЕНИЕ}
В ходе выполнения лабораторной работы №~4 была достигнута цель --- разработан и проведён сравнительный анализ последовательного и параллельного алгоритма трассировки лучей. Были выполнены все задачи:
\begin{enumerate}
	\item описан последовательный алгоритм решения задачи;
	\item разработан параллельную версию алгоритма;
	\item реализован обе версии алгоритма;
	\item выполнен сравнительный анализ зависимостей времени решения задач от размерности входа для реализации последовательного алгоритма и для реализации модифицированного алгоритма;
	\item выполнен сравнительный анализ зависимостей времени решения задач от размерности входа для реализации модифицированного алгоритма при $k \in \{1, 2, 4, 8, \dots, 8 \cdot q\}$, где $q$ --- количество логических ядер процессора;
	\item сформулирована рекомендация по выборе $k$ для решения поставленной задачи.
\end{enumerate}
